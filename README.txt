WEB ENGINEERING - LAB 07
Bootstrap 5: Containers, Grid Rows and Columns, Alerts, Cards and Buttons

FILES
- index.html: Complete solution for tasks (a) through (h).
- images/: Seven local SVG picture files used by the page.

HOW TO RUN
1. Extract the ZIP file.
2. Keep the index.html file and images folder together in the same project folder.
3. Open the folder in Visual Studio Code.
4. Open index.html and choose Open with Live Server.
   You can also double-click index.html to open it in a browser.
5. Bootstrap styling requires an internet connection. The pictures are stored locally and do not require internet.

TASKS INCLUDED
A. Container with two rows and two equal-width columns in each row.
B. Container-fluid with three rows: different-width columns, one full-width column, and three columns with img-fluid images.
C. Nested grid with two outer columns and two inner columns in the second outer column.
D. Grid-based form with labels and inputs in separate columns.
E. Success alert after a valid form submission.
F. Card with image, title, description and Read More button.
G. Three-column product card grid with image, product name and Add to Cart button.
H. Button group and examples of different button colours, sizes and styles.

NOTE
The images are local SVG illustrations bundled with the project, so they will display even without internet.
The form and cart are front-end demonstrations; no data or orders are sent to a server.
